# iec60617-symbol-generator

Biblioteca de simbolos IEC 60617 (SLD y MLD, LV y MV) en SVG y DXF.

- src/: cuerpo del plugin, con los simbolos por carpeta
- plugin/: entregable empaquetado (`iec60617-symbol-generator.plugin`) y fuente del manifiesto
- assets/: documento de referencia IEC 60617

Ver plugin/iec60617-symbol-generator/README.md
