# iec60617-symbol-generator

Biblioteca de símbolos IEC 60617 (SLD y MLD, LV y MV) en SVG y DXF.

- `src/`: cuerpo del plugin, con los símbolos por carpeta.
- `plugin/`: entregable empaquetado (`iec60617-symbol-generator.plugin`) y fuente del manifiesto.
- `assets/`: documento de referencia IEC 60617.
- `tools/`: scripts de build (SVG → DXF, empaquetado del plugin, catálogo Excel).

Detalle de símbolos, reglas de texto y versiones: [plugin/iec60617-symbol-generator/README.md](plugin/iec60617-symbol-generator/README.md).
